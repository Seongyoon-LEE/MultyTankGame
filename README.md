# 🚀 2D 멀티 TPS 탱크 전투 게임: MultyTankGame

**플레이어는 탱크가 되어 AI 헬기의 감시를 피해 다른 탱크들과 전투를 벌이는 멀티플레이 TPS 게임입니다.**

<br>

🎥 **게임 영상**  
https://youtu.be/oGMlPxy5L1Y

<br>

## ✨ 주요 기능

- **🧠 FSM 구조**: 상태 머신을 활용해 플레이어 및 AI의 상태를 체계적으로 관리  
- **🚁 AI 시스템**: 헬기는 맵을 순찰하다가 플레이어를 발견하면 공격 수행  
- **💥 최적화**: 이펙트 및 파티클을 오브젝트 풀링으로 관리하여 성능 향상  
- **🌐 멀티플레이 지원**: Photon 2 Networking을 통한 실시간 멀티플레이 구현  
- **🎵 사운드 관리**: 사운드도 오브젝트 풀링으로 재사용, 사운드 매니저로 일괄 제어  

<br>

## 🛠️ 개발 환경

- **Engine**: Unity  
- **Language**: C#
